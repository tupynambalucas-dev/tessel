## [0.1.0-alpha] - 2026-04-22

Initial alpha milestone establishing core architectural boundaries, atomic workflows, and documentation governance.

### Refactoring & Internal Architecture
- [REFACTOR] (governance): enterprise documentation restructure, centralizing strategic documents in `/docs` and establishing root-level entry points.
- [REFACTOR] (workflows): atomic workflows directory structure for automated, modular changelog and roadmap updates.
- [REFACTOR] (studio): redefine `@tessel/studio` as the automation and asset distribution hub.

### Documentation & Specifications
- [DOCS] (standards): consolidate coding style guide into a single source of truth at `docs/STYLEGUIDE.md`.
- [DOCS] (policy): enforce mandatory en-US for all code and technical documentation.
