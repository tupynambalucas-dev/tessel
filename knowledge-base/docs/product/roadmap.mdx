# Strategic Roadmap

This document outlines the development trajectory of the **Tessel** platform, categorizing goals into immediate implementation milestones and long-term architectural evolutions.

---

## Phase 1: Ecosystem Foundation & DGS

**Status:** In Progress  
**Focus:** Core infrastructure and authoritative movement.

- [ ] Unified Identity (SSO) foundation.
- [ ] Authoritative Rapier physics integration on the Dedicated Game Server (DGS).
- [ ] Client prediction and Geckos.io state interpolation.
- [ ] WebGPU/TSL base rendering pipeline for the 3D Instance.
- [ ] Monorepo structure finalized with `apps/` and `packages/` boundaries.

---

## Phase 2: High-Performance Social Hub

**Status:** Planned  
**Focus:** Persistent engagement and asynchronous interaction.

- [ ] Global and community social feeds.
- [ ] Private and group messaging systems via Socket.io.
- [ ] Marketplace core for virtual goods.
- [ ] Persistent inventory hub that syncs with 3D Instances.

---

## Phase 3: The Connected Experience

**Status:** Planned  
**Focus:** Seamless integration and global scaling.

- [ ] **Media Bridge**: Automatic 3D capture publishing to social feeds from the game instance.
- [ ] **Spatial Immersion**: Positional SFU (Selective Forwarding Unit) voice chat integration.
- [ ] **Interactive Objects**: Shared state objects in the 3D world synced via the DGS.
- [ ] **Infrastructure Scaling**: Global Agones orchestration for room instancing.
- [ ] **Stress Testing**: Handling high player density and tick-rate stability tuning.
