# ⚡ Quick Cheat Sheet

A comprehensive reference for developers to manage the **Tessel** monorepo, infrastructure, and automation.

---

## 🚀 Running the Platform

We use **Turborepo** to orchestrate applications and their respective infrastructure in a single command.

<Tabs>
  <TabItem value="dev" label="Full Stack" default>
    - **Start Everything:** `pnpm dev` (Starts Hub, API, and Game Server)
    - **Stop & Clean Everything:** `pnpm stop`
  </TabItem>
  <TabItem value="apps" label="Specific Apps">
    - **Hub Only:** `pnpm --filter @tessel/hub dev`
    - **API Only:** `pnpm --filter @tessel/api dev`
    - **Game Server Only:** `pnpm --filter @tessel/game-server dev`
  </TabItem>
  <TabItem value="docs" label="Documentation">
    - **Start Docusaurus:** `pnpm docs:dev`
    - **Build Docs:** `pnpm build` (Runs build for all workspaces including docs)
  </TabItem>
</Tabs>

## 🐳 Infrastructure (Docker)

Direct management of containerized services (Redis, MongoDB, Agones local cluster).

| Scope | Command | Description |
| :--- | :--- | :--- |
| **Infra** | `pnpm infra:up` | Starts local MongoDB, Redis, and Agones containers. |
| **Infra** | `pnpm infra:down` | Stops and removes infrastructure containers. |
| **Infra** | `pnpm infra:reset` | Wipes volume data and restarts infrastructure. |

---

## 📦 Workspace Management

Handling internal dependencies across apps and packages.

- **Add Dependency to Workspace:** `pnpm add <package> --filter <workspace>`
- **Clean All node_modules:** `pnpm clean` (Uses `npkill`)
- **Typecheck All:** `pnpm typecheck`
- **Lint All:** `pnpm lint`

## 🤖 AI & Studio (MCP)

Orchestrating the Model Context Protocol and design bridge.

- **Context7 Search:** (Via AI Agent) Deep research into documentation.

## 🏗️ Build Pipelines

- **Full Build:** `pnpm build`
- **Build Core:** `pnpm --filter @tessel/core build`
- **Build Game:** `pnpm --filter @tessel/game build`
